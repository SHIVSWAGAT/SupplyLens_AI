🚀 SupplyLens AI — Predictive Supply Chain Intelligence Platform

SupplyLens AI is a real-time, AI-powered control tower that transforms logistics from reactive tracking → proactive decision-making.

It combines machine learning, optimization, and real-time analytics to predict disruptions and recommend actions.

❗ Problem

Supply chains today:

Lack real-time risk prediction

React after disruptions occur

Cannot optimize decisions dynamically

👉 Result: delays, higher costs, poor efficiency

💡 Solution

SupplyLens AI builds a decision intelligence pipeline:

🧠 Predicts shipment delays using ML

🚨 Prioritizes critical alerts

🛣️ Optimizes routes (time, cost, risk)

🔮 Simulates scenarios before execution

👉 Enables proactive and data-driven decisions

⚙️ Key Features

📊 Control Tower Dashboard (KPIs + trends)

🌍 Real-time Shipment Tracking (map view)

🤖 ML Risk Prediction (delay probability + confidence)

🚨 Alert Prioritization (severity + root cause)

🛣️ Route Optimization (fastest / cheapest / safest)

🔮 Scenario Simulation

📈 Analytics (trends, performance)

🧠 AI Assistant (Nexus)

🧱 System Design

Modular architecture:

Frontend → Backend APIs → ML Layer → Data Sources

Designed for:

Real-time processing

Scalable components

Clear separation of concerns

🛠️ Tech Stack

Frontend: React, Vite, Tailwind, Leaflet

Backend: FastAPI

ML: Scikit-learn, Pandas, NumPy

Database: SQLite

Deployment: Netlify + Render

AI: Ollama (local LLM)

🧠 AI Assistant Setup (Important)

The Nexus AI Assistant uses Ollama (local LLM).

Install: https://ollama.com

Run: ollama run llama3

Public API keys are not included due to privacy and rate limits.

🧪 Run Locally

Backend:

cd backend
pip install -r requirements.txt
uvicorn main:app --reload

Frontend:

cd frontend
npm install
npm run dev
